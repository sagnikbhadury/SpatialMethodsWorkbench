# Reproducible vignettes

These vignettes use deterministic, deliberately small simulated datasets so the built-in workflows render quickly on a laptop and can be reproduced without protected or unpublished data.

1. [App walkthrough](app-walkthrough.Rmd) — create upload-ready CSV files, reproduce the app's mapping and readiness steps, run an analysis, and export a bundle.
2. [Spatial diagnostics and networks](spatial-networks.Rmd) — spatial autocorrelation, conditional networks, and opt-in public ISPat/GP-GHS engine calls.
3. [Prediction, clustering, and mediation](prediction-clustering-mediation.Rmd) — held-out prediction, spatially weighted clustering, a shallow neural network, and mediation.
4. [Imaging, shape, and 3D workflows](imaging-shape-3d.Rmd) — scalar-on-image screening, image-to-image screening, contour PCA, and an opt-in ISPAT-3D call.
5. [Reproducibility bundles](reproducibility-bundles.Rmd) — inspect and verify the downloadable results archive.

All computed values are synthetic demonstrations. The vignettes document execution, inputs, outputs, and reproducibility artifacts; they do not assign biological, clinical, or causal meaning to results.
